name: chat-handoff-prompt
description: "会話が長くなり新しいチャットに移行する際、経緯・ルール・進捗・未決事項を漏れなく引き継ぐプロンプトを作成する定型手順。"
---

新しいチャットへの引き継ぎプロンプトには、以下を含める。

1. **ルール**: このプロジェクトで守ってきた進め方のルール
   (preferences.md相当の内容)
2. **プロジェクト概要**: 基本情報、確定済みの主要仕様
3. **進捗状況**: 直近までに完了・push・CI成功した内容
4. **未決事項・次にやること候補**: 保留中の論点、着手していない
   タスク

詳細な経緯そのものは全て転記せず、「必要であれば過去のチャットに
確認してください」と添え、要点のみを簡潔にまとめる。
