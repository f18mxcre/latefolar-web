name: cross-ai-code-review
description: "Code側の実装報告やモックアップについて、ChatGPT等の他AIの意見を独立した第三者意見として扱いながらレビューする。コード・API仕様・DB設計・UI/UX・文言・モックアップ/イラスト・事実確認が必要な数値等を対象とする。"
---

このプロジェクトの技術スタック(バックエンド: TypeScript/Node、
iOS: Swift/SwiftUI、Android: Kotlin、公式サイト: 静的HTML/CSS)を
前提にレビューする。対象はコードに限らず、API仕様、DB設計、
UI/UXデザイン、文言、モックアップ・イラスト(画像生成物)、
事実確認が必要な数値・法令等も含む。

レビュー対象がコードの場合は、バグ・クラッシュ、セキュリティ、
パフォーマンス、設計・責務分離、可読性・保守性、テスト不足、
言語ごとのベストプラクティス、API設計、拡張性の順で確認する。
対象が仕様・UI/UX・文言の場合は、目的との整合性、既存の確定事項
との矛盾有無、想定外のスコープ拡大がないか、事実確認が必要な
主張の有無、を確認する。
対象がモックアップ・イラスト(画像生成物)の場合は、上記に加えて
「依頼していない要素が勝手に混入していないか」を確認する。画像に
写っているというだけで、それを仕様確定として扱わない。

以下を必ず守る:
- 他AI(ChatGPT等)の意見は独立した第三者の意見として扱い、単に
  同意するのではなく、賛成できる点・気になる点をそれぞれ具体的な
  理由とともに評価する
- 法令・料金・技術仕様など事実確認が必要な内容は、憶測で判断せず
  「要web検索確認」として明示する
- 新しい提案が、これまでの確定事項(design.md・過去の決定)と
  矛盾していないか確認し、矛盾があれば断定せず指摘に留める
- 想定されていた範囲を超えてスコープが広がっていないか確認する
- 対象年齢・対象読者に配慮が必要な表現が含まれる場合、不適切さや
  誤解を招く余地がないか確認する
- 「画像を目視確認して問題なし」と判断するのではなく、可能な限り
  機械的に検証する(例: 画像の切り出しなら元素材との境界比較、
  コードなら実際にビルド・テストを実行する等)。拡大表示・高解像度
  表示での確認だけでは、実際の使用サイズでの見え方の問題(視認性
  低下等)を見落とす可能性があることに注意する
